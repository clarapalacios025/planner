# Alia Planner

A native SwiftUI iPhone planner with a warm, binder-book feel. Still in progress.

## Features

- Six color themes: Bubblegum Pink, Lavender, Matcha Green, Burgundy, Light Blue, and Turquoise
- Binder rings and a paper-style daily page
- Add, edit, complete, and delete plans
- Optional reminders on each plan, delivered as local notifications
- A local account with the password stored in the iOS Keychain
- Alia, a kitten companion with prompts and a small chat sheet

## Running it

1. Open `AliaPlanner.xcodeproj` in Xcode.
2. Pick an iPhone simulator and press **Run**.

Turning on a reminder asks for notification permission and schedules a repeating notification at the time you choose. Turning it off cancels the notification.

## Built with

Swift, SwiftUI, UserNotifications, Keychain Services
